Python Insights - Análise de Dados com Python

Projeto de análise de dados desenvolvido em Python com foco na identificação dos principais fatores relacionados ao cancelamento de clientes.

Objetivo

Realizar uma análise exploratória dos dados para compreender padrões de cancelamento, identificar possíveis problemas e gerar insights que auxiliem na tomada de decisões.

Etapas do Projeto
Importação e tratamento da base de dados
Limpeza e organização das informações
Análise exploratória dos dados
Criação de gráficos e visualizações
Identificação de padrões e insights

Tecnologias Utilizadas
Python
Pandas
Plotly
Jupyter Notebook

Resultados
Através da análise dos dados, foi possível identificar comportamentos e características relacionadas ao cancelamento de clientes, permitindo uma melhor compreensão dos fatores que impactam a retenção.
